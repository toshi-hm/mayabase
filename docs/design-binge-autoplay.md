# 一気見自動再生の設計（#307）

カテゴリページとシリーズページの動画一覧に、表示順をそのまま使う一気見キューを埋め込む。ライトボックスで再生終了を検知したら、次の動画を同じダイアログ内で自動再生する。

- `data-binge-queue` はJSONを持たない単なる真偽値マーカー属性で、クリック時に祖先要素配下の `<li>`/`<template>` をDOM走査してキューを都度組み立てる(#419/#441のtemplate遅延実体化対応に合わせた変更)。
- `VideoLightbox.astro` はクリックされたトリガーの祖先(`[data-binge-queue]`)配下を `getQueueIncludingTemplates` で走査してキューを取得するため、カードの遅延実体化(`<template>` への格納)に依存しない。
- YouTube IFrame Player API は一気見キューが2件以上のときだけ遅延ロードする。APIが利用できない場合は現在の動画を通常どおり再生する。
- 末尾ではループせず、現在の閉じる操作を維持する。
- キューのJSONは実行時に再検証し、不正な動画IDやアスペクトは除外する。
