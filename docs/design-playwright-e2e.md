# ブラウザE2Eテストの設計（#375）

Playwrightで静的ビルドのプレビューをChromiumから操作し、Astroコンポーネント内のDOM配線を検証する。CIでは既存のCIジョブが生成した`dist/`をダウンロードしてプレビューし、ビルドを重複させない。

対象シナリオは、回帰影響が大きく外部サービスの応答に依存しない次の3本とする。

- 動画ライブラリ: カテゴリ絞り込み、`aria-pressed`、URL同期、キーワード検索、件数表示
- トップページ: カルーセルの自動切替停止、手動次スライド、選択ドット
- カテゴリページ: 一気見キューの存在、ライトボックス開閉、iframe自動再生URL

YouTube本体の再生完了は外部ネットワーク状態に左右されるため、この導入ではライトボックスの起動とキュー表示までをブラウザE2Eで確認し、IFrame APIの終了イベントによる遷移ロジックは純粋関数テストと実ブラウザの手動確認に分ける。テスト失敗時はtrace・スクリーンショット・動画・HTMLレポートをCI artifactへ保存する。
