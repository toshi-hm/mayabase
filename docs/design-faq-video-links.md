# FAQと動画の相互リンク設計

## 目的

FAQへ検索経由で着地した訪問者には関連動画を、動画詳細ページへ直接着地した訪問者には関連FAQを提示し、質問と回答・実例の行き来をしやすくする。

## 関連付けのルール

FAQ項目の \`link\` が動画個別URLまたはカテゴリURLなら、そのリンクを明示的な関連付けとして利用する。さらに、FAQ項目の任意の \`videoIds\` と \`keywords\` を利用して、動画タイトル・概要欄・カテゴリラベルを \`textMatchesKeyword\` で照合する。

判定は \`src/lib/faqVideos.ts\` に集約し、FAQページと動画詳細ページの両方から同じ結果を利用する。表示件数はFAQごとに最大3件とし、データ順(公開日時の新しい順)を維持する。

## URL

動画詳細ページからFAQへは \`/faq/?q=...\` へ遷移する。FAQページの既存検索処理がクエリを復元して一致項目を開くため、JavaScriptが有効な環境では質問へ直接到達できる。JavaScript無効時もFAQ一覧と関連動画リンクはサーバー描画される。
