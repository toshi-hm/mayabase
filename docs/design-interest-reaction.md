# 気になるリアクションの設計（#333）

ログイン不要の1クリック反応を既存のCloudflare KVへ reaction:動画ID というキーで集計する。KVはread-modify-writeであり厳密な同時実行加算ではないため、サイト内の軽量な人気シグナルとして扱い、ランキングの唯一の根拠にはしない。

同一訪問者自身の書き込みが再送で反映済みかどうかは判定している(#433)が、異なる訪問者同士がほぼ同時にリクエストした場合の取りこぼし(lost update)はKVの制約上あり得るため対策していない(#533)。Cloudflare KVはトランザクションやアトミックインクリメントを提供しないため、厳密な同時実行加算が必要な場合はDurable Object等への移行が必要になる。現状は上記の通り「軽量な人気シグナル」という位置づけのため、実用上の影響が小さいと判断しこの制約を許容している。

動画IDを正規表現で検証し、保存値には365日TTLを設定する。カードのボタンはJSが失敗しても視聴導線を妨げず、10件以上を話題の閾値とする。
